# 香港繁體介面

本地版本的介面文案使用繁體中文，統一「匯入、匯出、儲存、剪接、影片、音訊」等用語。沒有語言切換選單。

## 範圍

- 首頁、設定、素材匯入、聊天、時間線、預覽、匯出及無障礙標籤。
- 常見錯誤、素材分析進度、模型重試、工作預覽及最終失敗訊息。
- Agent、視覺摘要、鏡頭深入分析及預覽質檢的繁體輸出指引。
- 繁體／粵語指令的預覽、剪接、拍點及匯出意圖判斷；保留原有簡體相容性。

使用者文字、影片字幕、引用台詞、檔名、工具參數、舊對話和已儲存的分析資料不會自動轉換。技術診斷及第三方錯誤仍可能保留原始語言；模型遵從繁體指引的效果尚未用真實 API 驗證。

前端開發伺服器通常會自動更新；後端與 Agent 指引需重新啟動 `make dev` 才生效。
